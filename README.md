## Коротко

3,5 года коммерческой разработки. Начинал с 1С и производственной автоматизации, сейчас строю Python-сервисы, RAG-поиск и AI-агентов, которые убирают ручную работу.

**151 unit** в RAG-индексе · **3,4 млн символов** нормативки · **123 теста** в трёх backend/AI-проектах · **10 публичных репозиториев**

## Что делаю

- **RAG/LLM** — парсинг документов, структура «раздел → пункт», эмбеддинги Qwen3, векторный индекс, multi-query, RRF, self-reflective RAG.
- **Backend** — FastAPI, PostgreSQL, Redis, Celery, RabbitMQ, Docker Compose, миграции Alembic, CI, pytest.
- **AI-агенты** — LangGraph, LangChain, MCP, tool calling, structured output, human-in-the-loop, LangFuse.
- **Документооборот** — DOCX/XLSX, описи, реестры, Playwright-автоматизация, разбор имён и страниц.
