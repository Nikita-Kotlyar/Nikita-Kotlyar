3,5 года коммерческой разработки. Начинал с 1С и производственной автоматизации, сейчас делаю Python-сервисы, RAG-поиск и инструменты, которые убирают ручную работу.

- **Парсинг и интеграции**: BeautifulSoup, Playwright, PDF/DOCX/RTF, REST API, JSON, регулярные выражения.
- **Документооборот**: генерация DOCX/XLSX, описи, справки, перечни, подсчёт страниц, шаблоны.
